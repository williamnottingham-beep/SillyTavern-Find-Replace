# Chat Find & Replace

A compact SillyTavern UI extension for searching and replacing text across the active chat, with optional JavaScript regular expressions and saved rule presets.

Version: **1.1.1**

## Features

- A persistent icon button embedded beside the chat composer controls, so it stays accessible on desktop and mobile, plus `Ctrl+Shift+F` / `Cmd+Shift+F` on keyboards.
- Search and replace across all matching user messages, assistant messages, or both.
- Optional inclusion of system/note messages.
- Literal matching by default. **Regex mode** supports JavaScript regex syntax and custom flags. Global replacement is always enabled.
- Live preview showing match and affected-message counts, plus **Find next** navigation.
- Save named rules and reload/delete them later. Saved rules persist in SillyTavern extension settings.
- Optional bulk modification of alternate AI swipes. Off by default, so hidden alternate responses are not unexpectedly rewritten.
- Calls SillyTavern's message re-render and chat-save APIs. Markdown, display formatting and native Regex processing run through the standard rendering pipeline.
- Preserves the visible chat scroll anchor after replacement.
- Mobile-friendly panel positioning above the composer, virtual-keyboard resize handling, safe viewport sizing, larger touch targets, and layouts that wrap instead of overflowing.
- Detects an open Seamless Message Edit session and asks you to save or cancel it before bulk replacement.

## Install

1. Extract the ZIP.
2. Copy the `chat-find-replace` folder to `SillyTavern/data/<your-user>/extensions/`.
3. Refresh SillyTavern and enable **Chat Find & Replace** in the Extensions panel if needed.

For an all-users installation, place it under `SillyTavern/public/scripts/extensions/third-party/chat-find-replace/` if your setup supports that directory.

## Usage

1. Tap or click the search icon beside the chat input controls, or press `Ctrl+Shift+F` / `Cmd+Shift+F` when using a keyboard.
2. Enter the search and replacement text.
3. Leave **Regex mode** off for literal search. Turn it on to use JavaScript regex syntax, such as `\\b(cat|dog)\\b`, with flags such as `gi`.
4. Choose whether the operation targets User, AI, and optionally System/note messages.
5. Review the live match count, then select **Replace in chat**. A confirmation is shown before changing stored messages.
6. Under **More options & saved rules**, save named rules for later use. A saved rule includes its pattern, replacement, flags, message roles, and swipe options.

## Regex notes

- Enter a raw JavaScript regex pattern without slash delimiters. For example: `\\bcolour\\b`.
- Flags are entered without slashes. The `g` flag is always applied so all matches are replaced. The sticky `y` flag is ignored because it conflicts with a find-anywhere operation.
- Regex replacements use JavaScript replacement syntax, including `$1` for capture groups and `$&` for the full match.
- Invalid expressions are reported before any message is changed.

## Compatibility and safety behavior

- Operates on raw `chat[index].mes` values rather than formatted HTML. This avoids replacing text generated by formatting markup and allows SillyTavern to render the updated messages normally.
- Uses `updateMessageBlock`, `MESSAGE_EDITED` / `MESSAGE_UPDATED` events where available, and `saveChat` from `SillyTavern.getContext()`.
- When alternate swipes are excluded, only each message's active content is replaced and the active swipe is synchronized. When included, matching content in all assistant swipe variants is also replaced.
- The extension does not edit thinking/reasoning metadata, image/audio attachments, or other non-message metadata.
- For safety, bulk replacement is blocked while generation is active or while Seamless Message Edit has a message editor open.

## Troubleshooting

- If you updated to v1.1.0 and the composer button did nothing, install v1.1.1. The launcher is outside the extension panel container by design, so this version fixes selector lookup and uses a delegated click handler that survives composer rebuilds.

If the extension does not appear, check that the folder contains `manifest.json`, `index.js`, and `style.css`, then refresh SillyTavern and enable the extension. If SillyTavern core changes its extension context API in a future release, compatibility may need an update.
